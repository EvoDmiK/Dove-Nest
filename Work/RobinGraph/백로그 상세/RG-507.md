### RG-507 — n8n 새소리 수집·검토·허용 음원 저장

- **상태**: 진행 중 (구현·TEST 검증 진행 / 운영 미승인)
- **우선순위**: P2(보통) — 사용자 구현 승인
- **권장 담당**: Claude(backend·자료·검토/저장 계약), Antigravity(n8n workflow·TEST 배포·실제 실행), Codex(리뷰·통합·최소 리팩토링), Writer(기록)
- **목적**:
  - 새소리 후보 수집부터 검토 상태·허용 자료 저장과 제공까지 반복 가능한 TEST workflow를 마련한다.
  - 외부 요청 제한을 존중하면서 검토되지 않은 자료와 공개 가능한 자료를 구분한다.
- **범위 및 변경 목표**:
  - n8n에서 소량 수집 후보·검토 상태·허용 음원 저장/제공 흐름을 실행한다.
  - 정확한 종 동정·출처·라이선스·원 metadata·hash를 보존하고 검토/공개 gate를 적용한다.
  - 후보 수집과 CDN 다운로드/재생을 구분하고 Retry-After·backoff·재시도 제한 및 실패 상태를 기록한다.
  - 기본 수동 실행과 실제 TEST 검증으로 마무리한다. 주기 자동 수집은 별도 명시 활성화 전까지 꺼둔다.
  - 새 저장·제공 기능은 TEST 전용이다. Production API·DB·workflow 활성화·Git commit/push/merge는 포함하지 않는다.
- **예상 대상 파일 / 모듈**:
  - 기존 ingest/recordings·검토 자료 관리·저장/제공 경로, n8n workflow와 TEST 실행/배포 자산.
  - 최종 파일·API·DB target·저장 위치는 통합 작업기록의 실제 계약으로 확정한다.
