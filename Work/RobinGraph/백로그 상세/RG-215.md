### RG-215 — 조건으로 새 찾기(새 탐색기): 다중 조건 구조화 그래프 검색 및 탐색 인터페이스

- **상태**: 진행 중 (초안 등록 및 협업 착수 / TEST 구현·검증 대기, 완료 아님)
- **우선순위**: P2(보통) — 사용자 구현 승인
- **권장 담당**: Codex(검토·통합·TEST 배포), Claude(backend 구조화 검색·API), Antigravity(UI 탐색 인터페이스), Writer(기록·Obsidian 동기화)
- **등록 경위**: 2026-11-10 사용자 승인으로 협업 착수. 자연어 파서를 거치지 않고 기존 구조화 graph 검색을 재사용하여 다중 조건(분포·분류군·서식지·먹이) 기반으로 조류를 탐색하고 결과를 직관적으로 조회하는 기능 구현 등록.
- **목적**:
  - 자연어 입력 없이도 필터 선택만으로 분포, 분류군, 서식지, 먹이 조건을 조합하여 원하는 조류를 정밀하게 탐색할 수 있는 전용 인터페이스와 API를 제공한다.
  - 검색 결과의 생태적 근거, 출처, 데이터 커버리지, 도감 링크를 명확히 제시하여 정보 신뢰도를 확보한다.
- **범위 및 변경 목표**:
  - **분포 범위**: 4종 스코프(`all`, `korea`, `outside`, `unknown`) 완전 지원.
  - **분류군 필터**: 국명 또는 학명 기반 5대 계급(목·과·속·종·아종) 해소 및 일치 검색 (부모 형질의 묵시적 상속이나 계급 임의 확장 금지).
  - **서식지 및 먹이 복수 조건**: 다중 먹이 선택 시 **AND 조건** 적용 및 선택된 먹이 비율의 **합산 내림차순(DESC)** 정렬 (RG-214 정렬 엔진 재사용). 대표 서식지 일치 및 >0 먹이 비율 검증.
  - **자연어 파서 우회**: LLM / Jev / 벡터 의도 파서를 경유하지 않고 기존 고정 Cypher 구조화 그래프 쿼리(`graph_question_handler`)를 직접 재사용하여 결정론적이고 안전한 응답 보장.
  - **결과 정보 충실도**: 각 결과에 실제 증거 링크, 출처 명시, 자료 커버리지(자료 부재와 불일치 구분), 20건 상한 및 `has_more` 공개, 도감(Bird Profile) 연결 지원.
  - **UI 및 반응형**: 데스크톱(1280px) 및 모바일(390px) 뷰포트 지원, 키보드 인터랙션, 공유 가능한 URL 상태 복원(선택 필터 쿼리스트링 유지), 비동기 레이스 컨디션 방어.
- **예상 대상 파일 / 모듈**:
  - Backend: `src/robingraph/retrieval/graph_questions.py`, `src/robingraph/api/drf/views.py` (또는 전용 explorer API), 관련 테스트 스위트
  - Frontend: `src/robingraph/api/static/` (탐색기 전용 UI 폼, 컨트롤러, 스타일), 관련 UI 테스트
- **완료 기준 (Acceptance Criteria)**:
  - [ ] 구조화 API 호출 시 자연어 의도/LLM/벡터 검색을 호출하지 않고 선택된 모든 조건이 유지된다.
  - [ ] 분포 4종 스코프(`all`/`korea`/`outside`/`unknown`) 및 형질 미선택 시 필터링된 도감 또는 명확한 지원 상태를 반환한다.
  - [ ] 분류군 계급(목/과/속/종/아종) 해소 시 부모 형질 상속이나 계급 확대 없이 정확한 학명/국명으로 조회된다.
  - [ ] 서식지+먹이+분포+분류군 복합 질의 시 AND 조건, 실제 증거 URL, 대표 서식지, >0 먹이 비율, 합산 비율 내림차순 정렬이 검증된다.
  - [ ] 서식지 단독, 먹이 단독, 분류군 단독, 분포 단독 조회가 독립적으로 정상 동작한다.
  - [ ] 잘못된 쿼리/중복 쿼리에 대해 422 처리 및 미해소 분류군과 빈 결과가 명확히 구분된다.
  - [ ] 자료 부재(`insufficient_data`)와 검색 결과 없음(`empty`)이 시각적으로 구분되고 20건 제한 및 `has_more`가 정확히 표기된다.
  - [ ] 공유 URL을 통해 선택 필터가 정확히 복원되며 지연된 비동기 응답이 최신 상태를 덮어쓰지 않는다.
  - [ ] 데스크톱(1280px) 및 모바일(390px) 환경에서 가로 넘침이 없고 키보드 접근성이 준수된다.
  - [ ] 도감 프로필 링크가 선택된 스코프와 정규 학명을 유지하며 기존 채팅·도감·음원 기능과의 회귀가 없다.
  - [ ] TEST 환경 격리 배포 및 실사 검증이 완료되고 Production/DB 쓰기/Git 커밋은 미수행 상태를 유지한다.
- **실제 검증 계획**:
  - 자동화 단위/회귀 테스트: Python 백엔드 테스트 및 Node UI 테스트 실행
  - TEST 배포 및 실API 검증: `deploy_explorer_test.py` 기반 TEST 격리 배포 후 실제 HTTP 질의 매트릭스 검증
